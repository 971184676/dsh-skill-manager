## ⭐ 主推文(推荐)

```
我电脑上装了 153 个 AI 技能。

DeepSeek Harness 里,一个都看不到。

不是 DSH 的问题 —— 是技能散在 4 个互不相通的地方:

~/.claude/skills
~/.codex/skills
~/.gemini/skills
~/.agents/skills

DSH 只认其中一部分,其它的等于不存在。

先给你一条自查命令,不装任何东西也能用:

ls ~/.claude/skills ~/.codex/skills ~/.gemini/skills ~/.agents/skills 2>/dev/null | wc -l

如果这个数字 > 你在 DSH 里看到的技能数,你就是受害者。

我写了个开源插件解决它 🧵
```

**3/5 — 我做了什么**

```
所以我写了个 DSH 插件:

· 一次扫描全部技能目录(Claude / Codex / Gemini / AGENTS / DSH 内置)
· 按 name 合并去重 —— 同一个技能装 4 份,只显示一条,列出全部位置
· 侧边栏面板:分类、搜索、详情、删除(进回收站可恢复)
· 输入框打 / 就能按分类选技能,选中插入 @技能名
· 导出 Markdown / CSV / JSON
· 中英双语,MIT,零外部依赖
```

README 有完整步骤和排障手册。

## 🎯 发布技巧

| 技巧 | 原因 |
|---|---|
| **链接放第一条回复,不放正文** | X 算法会压低带外链正文的推荐权重 |
| **第一行独立成段** | 滑动时就能看到,不用点开 |
| **先给价值,再给产品** | 自查命令"不装也能用",读者会为这条点赞收藏 |
| **发布后置顶** | 主页访客第一眼看到 |
| **发布时间** | 北京时间 20:00–22:00,或美东 9:00–11:00 |
| **标签 2–4 个** | `#DeepSeek` `#AI` `#OpenSource`,堆多了反而降权 |
| **发完 10 分钟补一条** | 维持热度,例如补充"Claude Code / Codex 的技能目录同样能管" |
